# Deploy version notes — 2026-10-28

**Audience:** every git2 lane (Dash, Console, Codeplane, CI) and their coding agents.
**Scope:** git2 now runs with one `docker compose up`, and the first contracts of the Platform & Backup lane are ready for review: `backup.v1` and the gateway.

**Canonical reference:** [docs/api/compose.md](../../../api/compose.md), [docs/api/backup.md](../../../api/backup.md), [docs/api/gateway.md](../../../api/gateway.md), [docs/api/snapshot-format.md](../../../api/snapshot-format.md).
The API docs are the source of truth; this note only summarizes the change.

**Breaking?** No.

---

## 🟢 NEW — Compose stack

```bash
cd compose && cp env.example .env   # set POSTGRES_PASSWORD and JWT_SECRET
docker compose up -d --build        # add --profile git-svc for git-svc
curl http://127.0.0.1:8080/healthz
```

PostgreSQL 18, Redis (no persistence), a one-shot `migrate` that applies git2's `migrations/`, git2 core on `127.0.0.1:8080`, and git-svc on `git-svc:9090` inside the network. Images build from your sibling checkouts, or from a branch with `GIT2_SRC=<url>#<branch>`.

## 🟢 NEW — backup.v1 (contract v0)

`BackupService`: `CreateSnapshot`, `GetSnapshot`, `ListSnapshots`, `DeleteSnapshot`, `GetBackupSettings`, `UpdateBackupSettings`. Events `SnapshotFinished`, `SnapshotDeleted`, `BackupSettingsChanged`. Restore is a `git2ctl` command, not an RPC.

## 🟢 NEW — Gateway (contract v0)

Routes, sign-in checks, the headers upstreams receive (`X-Git2-User-Id`, `X-Request-Id`, `X-Real-IP`), limits and errors.

## ℹ️ FYI — decisions

- Image recipes live in git2-deploy and build from your repo ([ADR 0001](../../../decisions/0001-images-built-here-from-source-repos.md)).
- backup-svc lives in git2-deploy, like ci-svc in git2-runner ([ADR 0003](../../../decisions/0003-backup-svc-and-its-contract-live-here.md)).
- Proposed for W2 planning: the gateway as its own process, like GitLab Workhorse ([ADR 0004](../../../decisions/0004-gateway-is-its-own-process.md)).
