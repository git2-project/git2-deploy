## ⚪ FYI: snapshot format v1

- `manifest.json` is the last archive entry and lists every other entry with size and sha256. A restore accepts a snapshot only when the archive matches `snapshot.json`, decrypts with the operator's key, and every entry matches the manifest, with nothing extra and no unsafe path.
- An empty repository is an empty `.bundle`. A repository deleted during the snapshot (git-svc NOT_FOUND) is left out.
